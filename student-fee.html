ফি ম্যানেজমেন্ট

Student ID box-এ আগে থেকেই 100 থাকবে। বাকি 3 digit লিখলেই student search হবে।

👨‍🎓 শিক্ষার্থীর তথ্য

Example: 100123 — 6 digit পূর্ণ হলে data auto আসবে।

📅 মাস নির্বাচন করুন

Student পাওয়া গেলে current month auto select হয়ে input form খুলে যাবে। মাস change করলে input form auto refresh হবে।

💳 পেমেন্ট ও রিসিপ্ট সেটিংস

Custom receipt no দিলে সেটাই ব্যবহার হবে। না দিলে auto generate হবে।
Calendar/clock নেই। Text হিসেবে date and time লিখুন। খালি রাখলে current date/time যাবে।

Receipt Generate = শুধু receipt/PDF হবে, sheet-এ submit হবে না। Submit = শুধু sheet-এ save হবে, receipt হবে না। Submit + Receipt = save হবে এবং receipt print/open হবে।

🔍 ফি অনুসন্ধান

Student ID search করতে 100 এর পরে 3 digit লিখুন। Receipt ID হলে পুরো Receipt ID লিখে Search করুন।
